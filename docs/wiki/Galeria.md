# Galeria do jogo

Seleção de retratos, inimigos e folhas de itens já existentes no projeto. As imagens são copiadas sem edição para que a Wiki possa exibi-las independentemente do carregamento do Unity. A galeria não é uma aprovação visual das cenas nem prova que cada arte esteja montada em todo contexto.
