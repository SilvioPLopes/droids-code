# Sprites de itens

Folhas novas em Consumo, Tecnologia e Especiais; recortes individuais em Recortes, nomeados pelo ID do item.

Para trocar a imagem de um item, abrir no Unity **DroidsCode → Itens → Abrir catálogo visual** e substituir somente a referência Sprite da entrada correspondente.

[Guia, origens e mapa de referências](../../../docs/guias/icones-de-itens.md). Os arquivos antigos em Atualizados/novos foram preservados.
